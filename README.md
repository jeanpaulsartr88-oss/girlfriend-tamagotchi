# 💖 Тамагочи Лёли ✨ (Pou / My Talking Tom Edition)

Интерактивная 3D-игра «Виртуальный питомец» в стиле Pou / My Talking Tom в формате **Telegram Mini App (TWA)** с бэкендом на Flask, процедурным 3D-оживлением Three.js и живой интеграцией с Telegram Bot API (@Lelya8_bot).

---

## 🎮 Игровые механики и возможности

### 1. 3D-сцена и процедурная анимация (Three.js)
- **Процедурное дыхание:** модель плавно покачивается по оси Y и покачивает корпус по оси Z в реальном времени.
- **Look-At трекинг:** голова и шея поворачиваются вслед за пальцем/курсором (`lerp`).
- **Squash & Stretch (Pou style):** при тапе по телу персонажа модель упруго сжимается и расширяется с GSAP-анимацией (`elastic.out`) и виброоткликом (Telegram Haptic Feedback).
- **Студийное освещение и тени:** мягкий AmbientLight + DirectionalLight спереди/сверху + контактная тень под ногами.

### 2. Четыре интерактивные комнаты
1. **🍕 Кухня (Food):**
   - Меню еды: Пицца (+25%), Яблоко (+15%), Тортик (+30%), Кофе (+10% энергии, +5% сытости).
   - Еда плавно летит в область рта с анимацией поедания и жевания.
   - Персонаж радостно подпрыгивает; при 100% сытости мотает головой (отказ от еды).
2. **🧼 Ванная (Bathroom):**
   - Инструмент «Мыло»: вождение пальцем по персонажу порождает переливающиеся мыльные пузыри, заполняя шкалу чистоты.
   - Кнопка «Душ»: струи воды смывают всю пену с освежающим звуковым эффектом.
3. **🛏 Спальня (Bedroom):**
   - Ночник «Выключить свет»: Three.js свет плавно угасает, небо темнеет со звёздами и луной, персонаж опускает голову и засыпает.
   - Во сне энергия восстанавливается с ускоренной скоростью (+1.5%/мин), а над головой всплывают символы «Z-z-z».
4. **🎮 Игровая (Playroom & Mini-Games):**
   - Режим «Пощекотать»: свайпы по щекам/голове вызывают смех, сердечки и рост настроения.
   - Мини-игра «Лови подарки»: 30-секундный аркадный режим ловли падающих сердечек и подарков для фарма очков и настроения.

### 3. Игровой цикл и оффлайн-прогресс
- 4 шкалы потребностей: **Сытость**, **Энергия**, **Чистота**, **Настроение** (0–100%) в Glassmorphism-стиле.
- Автоматический расчёт оффлайн-прогресса при возвращении в игру по разнице времени (`Date.now() - petState.lastUpdate`).
- Встроенные звуковые эффекты через WebAudio API (без внешних MP3-файлов).

### 4. Романтическая забота парня через Telegram
- **Критический алерт:** если сытость, энергия или настроение падают ниже 20%, бот отправляет сообщение парню в Telegram (`TELEGRAM_CHAT_ID`):
  > *«⚠️ Внимание! Твоя любимая Лёля грустит или голодает! Параметры: Сытость: X%, Энергия: Y%, Настроение: Z%»*
- **Интерактивные Inline-кнопки парня:**
  - `❤️ Погладить дистанционно`
  - `🍕 Заказать вкусняшку`
  - `💌 Чмокнуть в щёчку`
- **Мгновенный отклик на экране девушки:** нажатие кнопки парнем запускает фейерверк из конфетти и сердечек, всплывает модальное окно с сообщением заботы, и все шкалы восстанавливаются на 100%!

## 🚀 Архитектура и стек технологий

- **Backend:** Python (Flask + SQLAlchemy ORM + SQLite).
- **Frontend:** Single Page Application (HTML5, Tailwind CSS, Three.js r128, GSAP, WebAudio API, Canvas Confetti).
- **Telegram Mini App:** Telegram WebApp SDK (haptic feedback, safe-area layout, viewport fit).
- **Хостинг:** Render.com (`Procfile`, `requirements.txt`) + эндпоинт `GET /health` для UptimeRobot.

## 🛠 1. Настройка Telegram Бота и кнопки Mini App

### Шаг 1. Создание бота в @BotFather
1. Открой Telegram и найди **[@BotFather](https://t.me/BotFather)**.
2. Отправь команду `/newbot`.
3. Задай имя и юзернейм (например, `@Lelya8_bot`).
4. Скопируй полученный HTTP API Token в `.env` (`TELEGRAM_BOT_TOKEN`).
5. Узнай свой `TELEGRAM_CHAT_ID`: напиши боту **[@userinfobot](https://t.me/userinfobot)**.

### Шаг 2. Настройка кнопки Mini App (`Menu Button`)
1. В диалоге с **[@BotFather](https://t.me/BotFather)** отправь команду `/setmenubutton`.
2. Выбери своего бота.
3. Отправь URL развёрнутого приложения: `https://girlfriend-tamagotchi.onrender.com`.
4. Введи текст для кнопки: `💖 Играть с Лёлей ✨`.

## ⏱ 2. Настройка UptimeRobot на URL `/health`

Бесплатный тариф Render усыпляет инстанс при отсутствии активности. Чтобы игра всегда открывалась мгновенно:
1. Зарегистрируйся на **[UptimeRobot](https://uptimerobot.com/)**.
2. Создай новый монитор:
   - **Monitor Type:** `HTTP(s)`
   - **Friendly Name:** `Lelya Tamagotchi Keepalive`
   - **URL:** `https://girlfriend-tamagotchi.onrender.com/health`
   - **Monitoring Interval:** `5 minutes`
3. Нажми «Create Monitor».

## 💻 3. Локальный запуск

1. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запусти сервер:
   ```bash
   python app.py
   ```
   (или запусти `start.bat`)
3. Открой в браузере: `http://localhost:8000`.
