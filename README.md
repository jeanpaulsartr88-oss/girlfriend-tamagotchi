# 💖 Тамагочи Лёли / Live-мониторинг (Telegram Mini App)

Романтично-ироничное веб-приложение в формате **Telegram Mini App (TWA)** с интерактивной 3D-моделью Лёли, почасовыми чекинами её состояния и живой интеграцией с Telegram Bot API (@Lelya8_bot).

Девушка двигает ползунки своего состояния и отправляет отчёты, сверху в реальном времени живёт интерактивная 3D-модель (Three.js), а парню в Telegram прилетает стильное сообщение с эмодзи-индикаторами и кнопками мгновенных реакций (обнять, заказать вкусняшку, поцеловать). При клике парня у девушки прямо на экране срабатывает реакция, тактильный отклик (Haptic Feedback) и сыплются 3D-сердечки!

---

## 🚀 Архитектура и стек технологий

- **Backend:** Python (FastAPI + Uvicorn) — асинхронный бэкенд, обработка вебхуков Telegram и long-polling для локального теста.
- **Frontend:** Single Page Application (HTML5, Tailwind CSS, Vanilla JS, Telegram WebApp SDK).
- **3D Viewer:** Three.js (r128) + `GLTFLoader` + `AnimationMixer` + процедурный fallback с анимацией дыхания, покачивания и моргания.
- **База данных:** SQLite + SQLAlchemy ORM (автоматическое создание таблиц при старте).
- **Инфраструктура:** Готовность к бесплатному развёртыванию на Render.com + эндпоинт `/health` для UptimeRobot.

## 🛠 1. Настройка Telegram Бота и кнопки Mini App

### Шаг 1. Создание бота в @BotFather
1. Открой Telegram и найди официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправь команду `/newbot`.
3. Введи имя бота (например, `Любимая Тамагочи`) и его юзернейм (например, `my_sweet_tamagotchi_bot`).
4. Скопируй полученный **HTTP API Token** (вида `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`).
5. Узнай свой `TELEGRAM_CHAT_ID` (Chat ID парня): напиши боту **[@userinfobot](https://t.me/userinfobot)** — он пришлёт твой числовой ID (например, `987654321`).

### Шаг 2. Настройка кнопки Mini App (`Menu Button`)
Чтобы у девушки в чате с ботом в левом нижнем углу всегда была удобная кнопка запуска Mini App:
1. В диалоге с **[@BotFather](https://t.me/BotFather)** отправь команду `/setmenubutton`.
2. Выбери своего бота.
3. Отправь URL твоего развёрнутого приложения (например, `https://my-tamagotchi.onrender.com`).
4. Введи текст для кнопки (например, `💖 Открыть Тамагочи` или `Мой статус ✨`).

Готово! Теперь при нажатии на кнопку внизу чата у девушки открывается полноэкранное веб-приложение.

## 👗 2. Куда положить файл 3D-модели `girl.glb`

1. Положи свой файл 3D-модели по пути:
   ```text
   static/models/girl.glb
   ```
2. **Как работает 3D-вьювер:**
   - Вьювер автоматически загружает модель из `/static/models/girl.glb`.
   - Если в файле есть скелетные анимации, они автоматически связываются с состояниями:
     - `Idle` — спокойное дыхание / улыбка (базовое состояние).
     - `Happy` / `Dance` — когда Сытость > 70% и Энергия > 60%.
     - `Tired` — когда Энергия < 30%.
     - `Angry` / `Sad` — когда Сытость < 30% или Стресс > 70%.
   - **Встроенный Fallback:** Если вы загрузили статичную модель без костей или анимаций, либо файл ещё не заменён, вьювер автоматически применяет процедурное дыхание (`Math.sin(clock.getElapsedTime())`), покачивание, моргание глаз и интерактивное вращение — сцена никогда не падает с ошибкой!

## ⏱ 3. Настройка UptimeRobot на URL `/health`

Бесплатный тариф Render.com переводит веб-сервисы в спящий режим («Spin Down») при отсутствии запросов в течение 15 минут. Чтобы бот и сайт всегда отвечали мгновенно:

1. Зарегистрируйся на бесплатном сервисе **[UptimeRobot](https://uptimerobot.com/)**.
2. Нажми **«+ Add New Monitor»**.
3. Заполни поля:
   - **Monitor Type:** `HTTP(s)`
   - **Friendly Name:** `Tamagotchi Girlfriend Health Check`
   - **URL (or IP):** `https://твой-домен.onrender.com/health` (или `/ping`)
   - **Monitoring Interval:** `Every 5 minutes` (Каждые 5 минут)
4. Нажми **«Create Monitor»**.

Теперь UptimeRobot будет каждые 5 минут отправлять `GET /health` (возвращает `{"status": "ok"}`), и сервер на Render никогда не уснёт.

## 🚀 4. Развёртывание на Render.com

1. Запушь проект в свой GitHub-репозиторий.
2. Войди в панель **[Render.com](https://render.com/)** и нажми **«New +» -> «Web Service»**.
3. Подключи свой GitHub-репозиторий.
4. Настройки сервиса:
   - **Name:** `tamagotchi-girlfriend` (или любое другое)
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. В разделе **Environment Variables** добавь переменные:
   - `TELEGRAM_BOT_TOKEN` = `твой_токен_бота`
   - `TELEGRAM_CHAT_ID` = `chat_id_парня`
   *(Render автоматически создаст переменную `RENDER_EXTERNAL_URL`, и приложение само зарегистрирует вебхук для Telegram Bot API).*
6. Нажми **«Create Web Service»**.

## 💻 5. Локальный запуск и тестирование

1. Склонируй репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd <ПАПКА_ПРОЕКТА>
   ```

2. Создай и активируй виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux / macOS:
   source venv/bin/activate
   ```

3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env` и укажи токен:
   ```bash
   cp .env.example .env
   ```
   В `.env` для локального тестирования интерактивных кнопок Telegram установи:
   ```env
   USE_POLLING=true
   ```

5. Запусти сервер:
   ```bash
   python main.py
   # Или через uvicorn:
   uvicorn main:app --reload --port 8000
   ```

6. Открой в браузере: `http://localhost:8000`.

## 💖 Как устроена интерактивная магия

1. **Чекин:** Девушка выбирает интервал, двигает ползунки, кликает теги и жмёт кнопку. Бэкенд сохраняет запись в SQLite и отправляет парню красивое HTML-сообщение с прогресс-барами:
   - 🍕 Сытость: `[🟩🟩🟩🟩🟩⬜⬜] 70%`
   - ⚡ Энергия: `[🟩🟩🟩🟩🟩⬜⬜] 75%`
   - 🤯 Стресс: `[🟨🟨⬜⬜⬜⬜⬜] 25%`
   - 🥺 Скучаю: `[❤️❤️❤️❤️❤️❤️⬜] 85%`
2. **Критический алерт:** Если сытость < 30% или энергия < 20%, бот добавляет тревожный алерт парню: *«🚨 Внимание! Критический уровень истощения/голода! Срочно организуй подкрепление или заботу!»*.
3. **SOS-кнопка:** «Срочно похвали / скажи, что любишь» моментально шлёт экстренный пинг.
4. **Интерактивные ответы парня:** Под каждым отчётом парень видит кнопки:
   - `❤️ Обнять`
   - `🍫 Заказать вкусняшку`
   - `👀 Горжусь`
   - `💌 Чмок в носик`
5. Когда парень нажимает кнопку в Telegram, статус мгновенно попадает в базу, а у девушки на экране воспроизводится приятный перезвон (Web Audio API), включается тактильная вибрация и аватар танцует в салюте из 3D-сердечек!
